# MIP Drafts Console

A single-file browser tool for the Peer Review Performance (PRP) team. You upload a MIP Summary Report export from Power BI and it:

- drafts reminder emails for editors, triage editors, EAs and reviewers
- flags delayed editors
- builds Chief Editor escalation workbooks
- produces an audit export showing what happened to every manuscript

**Since v2.0, the console merges the Editor Delay Tracker (Daniel) into the MIP Drafts Console (Gayatri).**

## Using it

1. Download `mip-drafts-console.html` and open it in Chrome or Edge by double-clicking it.
2. On the **Editor, Triage & EA Drafts** tab, Step 01, drop in the MIP Summary Report export.
3. Check the settings in Step 03, then click **Generate all drafts**.

Everything runs locally in the browser. No data is uploaded anywhere, and nothing is kept after the page closes. The only external resource is the SheetJS library, loaded from cdnjs.

Former Editor Delay Tracker users should read [`docs/edt-user-guide.html`](docs/edt-user-guide.html).

## Changing email wording

Email wording is no longer in the code. It lives in `templates/templates.json`, and a copy is built into `mip-drafts-console.html`. Tables and manuscript lists are always generated by the tool, so they can't be edited.

1. Open `admin/template-admin.html` in Chrome or Edge, then click **Open templates…** → `templates/templates.json`.
2. Edit the wording. Use `{{placeholders}}`, `**bold**`, `*italic*` and `[link](url)`. The preview updates as you type. Errors such as a missing required line or a placeholder that isn't available in that email block the release.
3. Click **Save & release…** and enter the new version, the approver and what changed. Then click **Update console file…** and pick `mip-drafts-console.html`.
4. Two files download. Save them over `templates/templates.json` and `mip-drafts-console.html` in this repo.
5. In GitHub Desktop, check the diff and commit. The console footer shows the template version and approver, so anyone can see which wording they're using.

Only approved wording should be released. Who approves is still an open decision (EM-1 / EM-7).

## Data handling

- **Never commit Power BI exports** or any file containing manuscript, author or editor data. `.gitignore` blocks `.xlsx`, `.xls` and `.csv` files.
- The three Power BI screenshots that showed real manuscript data were removed from `mip-drafts-console.html` on 15 Oct 2026. The `archive/` copy of the original MIP console still contains them, so **keep this repository private**.
- **Deployment** happens from `wiley/mip-drafts-console-ea`, whose `public-html/index.html` is a copy of `mip-drafts-console.html`. Copy it across on each release.
- The files in `docs/` include editor names and manuscript IDs from the test export.
