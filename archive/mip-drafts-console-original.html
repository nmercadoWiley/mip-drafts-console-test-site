03Set thresholds

Controls the grace period and stale-invite cutoff that decide what counts as "needs a reminder."

Used as the To: address on both Reviewer Invitation Monitoring drafts.
"Handling Editor to Invite Reviewers" is flagged only if the editor hasn't acted within this many days — measured from the Activity Tracker's "Days Since Last Editor Action Date" when that file is uploaded (any editor activity counts), or from the Summary Report's "Days Since Last Reviewer Invited" if it isn't. If neither value exists for a manuscript, it's flagged immediately, since there's no record of the editor having done anything yet. Health Check is shown in the table for context but never overrides this day-based decision — a manuscript that's 66 days stale gets flagged regardless of what Health Check says. This is the only stage this setting affects: Reviews Pending, Ready for Decision, and Triage actions are always pulled in immediately with no grace period at all, since the editor can act on those directly — making a recommendation, a decision, assigning associate editors, etc. — regardless of how recently reviewers were invited.
EA summary #2: manuscripts where more than this many reviewers have been invited, with zero accepted and zero submitted.

12Draft status export

Downloads your original Summary Report exactly as uploaded, with 8 new columns added at the end recording what happened to each manuscript this run: whether it was drafted, to whom, when, why it wasn't (if it wasn't), whether it tripped the data-quality check from Step 04, and which color it's highlighted.

ColumnHow it's filled
EA Reminder Sent OnToday's date, only for rows in "Reviews Pending" (the bucket whose summary line says reminders are already sent). Blank otherwise.
In Email Draft?Yes / No — whether this row landed in any draft this run.
Email Drafted OnToday's date, for rows marked Yes.
Email Drafted ToThe editor/triage editor email the row was drafted to.
Email Drafted ActionThe bucket/section this row was sorted into (e.g. "Handling Editor to Invite Reviewers").
Not-Drafted ReasonOnly filled when "In Email Draft?" is No — explains why: Author-stage, EA-side task, or within the invite grace period (with the exact days-since-last-action used).
Data Check: No Decision & Blank Task Performer NameYes / No — the same data-quality check shown as a stat in Step 04's Analysis Summary, repeated here per row.
Row Highlight CategoryOne of: In Draft, Excluded - Author Stage, Excluded - EA-side Task, Skipped - Grace Period, Excluded - V1 Setting, Excluded - Sent as Separate Sheet. The whole row is also color-highlighted to match, via a conditional-formatting rule keyed off this column — see the color key below.

FYI — row color key

Row colorMeaning
 Data Check — in an active editorial stage with no decision recorded and no named Task Performer (see Step 04). Checked first, so it overrides every other color below.
 In a draft — this manuscript landed in an editor or triage editor's email this run
 Author-stage — excluded, the required action belongs to the author, not the editor
 EA-side task — excluded, e.g. Quality Checker / Material Checker / Screener / Submission Checker / Revision Checker / Editorial Assistant
 Within grace period — the editor has acted recently enough that this is held back for now
 V1 excluded — left out of editor drafts by your V1 setting (still included in Reviewer Invitation Monitoring)
 Reviews Pending excluded — left out of the Handling Editor draft by your setting; downloaded separately instead
